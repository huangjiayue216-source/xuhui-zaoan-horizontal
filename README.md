# 徐汇你早 · 横版图片文字编辑器

一个傻瓜式的本地网页：换照片、改日期、改配文，一键导出整图 PNG。

## 两种用法

| 方式 | 怎么用 | 数据存在哪 |
| --- | --- | --- |
| **在线版（GitHub Pages）** | 直接打开网址就能用，不用装任何东西 | 存在你自己浏览器的本地存储里（IndexedDB）；同一浏览器的多个标签页/窗口会自动同步 |
| **本地版（推荐给日常使用）** | 双击 `启动.bat`，浏览器打开 `http://127.0.0.1:5311/` | 存在项目文件夹的 `data\state.json`，可随时备份/拷贝；同一台电脑多个窗口共用同一份数据 |

两种方式界面完全一样，导出的 PNG 也完全一样。

## 一、怎么启动

1. 双击 **`启动.bat`**。
2. 浏览器会自动打开 `http://127.0.0.1:5311/`（没自动打开就手动输入这个地址）。
3. 用完后 **关闭那个黑色命令行窗口** 即可停止服务；也可以双击 `停止.bat`。

不需要安装 Node.js、Python 或任何东西，用的是 Windows 自带的 PowerShell。
你改的内容会自动保存在 `data\state.json`，下次打开还在。

## 二、界面就三块（左侧从上到下）

### 1. 日期 —— 左上角紫色框里的字

| 项 | 说明 |
| --- | --- |
| 月份 / 日期 / 星期 | 直接改字；「星期」在画面里是**竖排**显示的（和模板一致） |
| 农历年 / 农历 | 直接改字，例如 `丙午马年`、`九月初三` |
| 选日期 + 用今天 | 自动填好公历的月份、日期、星期，**并同时换算农历年和农历月日**（含闰月） |

### 2. 图片

- **上传 / 替换照片**：选一张照片放进中间空白处；已经有照片时会直接替换掉它。
- **删除照片 / 铺满照片区**：删掉或让它刚好铺满照片区。
- **撤销 ↶ / 重做 ↷**：任何操作都能回退。
- **替换模板 / 恢复默认 / 删除模板**：换掉整张背景版式，或恢复成原始模板。

照片和模板都在画面里直接调：**拖动移动、四角缩放、上方圆点旋转**；照片也可以直接从文件夹**拖进网页**。

### 3. 配文 —— 照片下方的文字

- 在文本框里直接写，回车换行。
- 默认字号 50px，与样式图一致。
- 还能改字号，以及复制 / 粘贴文字。

> 左上角日期文字和下方配文统一使用内置字体 **思源宋体 Bold**
> （`assets/fonts/SourceHanSerifCN-Bold.otf`，已随网站一起提供，换电脑也不用另装字体）。

### 导出图片

在左侧栏最底部（**滚动时它一直固定在底部**）——点一下就导出一张 1276×2846 的 PNG。

## 三、以后想换「底图模板」怎么办

这里的「底图模板」指的是整版背景那一层（紫色日历框 + 白卡片 + 二维码），和用户上传的照片是两回事。

**换默认底图（所有人打开都看到新的）：双击 `换底图.bat`**

1. 双击 `换底图.bat`，或者把新底图图片直接拖到 `换底图.bat` 上；
2. 选好图片（建议 1276 × 2846 的 PNG，中间留透明区），等它跑完；
3. 本地版刷新浏览器就能看到；线上版 GitHub Pages 约 1~2 分钟后自动更新。

脚本会自动做完下面这些事（不用碰代码）：

- 识别新底图里的**透明照片区**，同步更新照片该放的位置；
- 生成带版本号的新底图文件（文件名一变，浏览器缓存立刻失效，不会看到旧图）；
- 更新代码里的默认底图和照片区；
- 自动 `git commit` 并推送到 GitHub。

用户已经上传的照片、改过的文字**都不受影响**——照片是叠在照片区上的一层，换底图只是换背景。

## 四、快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 复制 / 粘贴文字 | `Ctrl+C` / `Ctrl+V` |
| 删除选中元素 | `Delete` |
| 微调位置 | 方向键（按住 `Shift` 每次 10px） |
| 立即保存 | `Ctrl+S` |

## 五、多窗口 / 多标签

同一台电脑上打开多个窗口，共用同一份数据：

- 任一窗口改完约 1 秒自动保存；
- 其它窗口 1.5 秒内自动同步；
- 两边同时改时会提示，以最后保存的为准。

## 六、文件说明

```
启动.bat / 停止.bat     启动、停止本地服务
换底图.bat              一键更换默认底图（含 replace-template.ps1）
server.ps1              本地服务（静态文件 + 数据存取）
index.html / css / js   网页界面与编辑器逻辑
assets/template.png     默认模板底图
assets/fonts/           内置字体（思源宋体 Bold）
data/state.json         你保存的数据（自动生成）
data/state.backup.json  上一次保存的备份（自动生成）
```

## 七、常见问题

- **左侧栏内容看不全**：用鼠标滚轮在左侧栏上滚动即可，最下面的「导出图片」始终可见。
- **提示端口被占用**：服务会自动往后找可用端口，命令行窗口里会显示实际地址，按那个地址打开。
- **浏览器打不开**：手动访问 `http://127.0.0.1:5311/`；改过端口就以命令行窗口显示的为准。
- **改了代码看不到效果**：在浏览器里按 `Ctrl+F5` 强制刷新。
- **想彻底重来**：关掉命令行窗口，删掉 `data\state.json`，再双击 `启动.bat`。
